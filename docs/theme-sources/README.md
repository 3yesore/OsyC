# OsyC theme source review

The review clones live outside this repository so they cannot accidentally enter the plugin bundle:

`C:/Users/Y2516/WorkBuddy/osyc-theme-sources-20260911`

Open each project README and its included preview images to compare:

- `obsidian-minimal`: native variable system, content width, image grids, desktop/mobile balance.
- `obsidian-border`: dense information hierarchy, card layout, Chinese documentation, Style Settings presets.
- `obsidian-things`: iOS-oriented spacing, touch targets, code blocks and image cards.
- `anuppuccin`: broad visual palette reference only; GPL-3.0 and currently on hiatus.
- `chinese-writing-layout`: Chinese long-form typography, local font import and paper/background controls.
- `codex-style-markdown`: Reading/Live Preview parity, responsive code/table/media behavior.
- `codesplash-themes`: semantic token and preset editor model.
- `obsidian-image-layouts`: image/caption/layout schema.

The exact snapshot commit and license for every source are recorded in `docs/changes/codex-2026-09-11-font-catalog-and-theme-research.md`.
