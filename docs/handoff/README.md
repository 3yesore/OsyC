# OsyC Handoffs

Handoffs make work resumable across agents and sessions. Store one Markdown file per completed or paused task in this directory, using a descriptive name such as `2026-09-11-theme-preview.md`.

Use `docs/coordination/agent-handoff-template.md` and include the exact branch commit, test commands, remaining work, and immutable items that the next agent must not alter. A handoff is complete only when its change record and verification evidence are linked.
