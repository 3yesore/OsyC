# Bundled OsyC fonts

OsyC embeds a small subset of the following fonts in `styles.css` so BRAT-installed mobile copies work without a separate font download. The binaries are unchanged WOFF2 files distributed by `@fontsource` 5.3.0 and remain under the SIL Open Font License 1.1.

- Noto Sans SC, Google Inc., Simplified Chinese subset, weights 400 and 600
- Inter, The Inter Project Authors, Latin subset, weights 400 and 600
- JetBrains Mono, The JetBrains Mono Project Authors, Latin subset, weights 400 and 600

The complete OFL text and copyright notices are included in the three `*-LICENSE.txt` files. Source package references are recorded in `SOURCES.txt`.
