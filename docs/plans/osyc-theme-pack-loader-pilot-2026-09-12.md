# OsyC 原始主题包装载试点

## 目标

验证 OsyC 是否可以在插件资源包内携带 MIT 许可的原始 Obsidian 主题 CSS，并通过 token 选择、启用、切换和回滚，同时保持 OsyC Agent 与笔记内容的兼容边界。

## 试点范围

- 主题：Minimal、Chinese Writing Layout。
- 资源：原始 CSS、许可证、来源 commit 和主题元数据；不带主题仓库的构建工具、示例库或远程依赖。
- 模式：`notes`（默认，限定 Markdown 内容）和 `workspace`（显式开启，覆盖 Obsidian 工作区）。
- 生命周期：一次只挂载一个主题包；切换时先移除旧节点，失败时恢复旧节点；插件卸载时全部移除。

## 实施步骤

1. 在 `src/osyc/theme/themePack.ts` 建立主题注册表、元数据解析、CSS 作用域策略和加载器接口。
2. 在 `assets/themes/` 放入两个固定 commit 的原始 CSS 与许可证副本，构建时复制到插件目录 `themes/`。
3. 在设置页增加主题包选择和作用域选择，旧的 OsyC token 预设保持兼容并作为适配层叠加。
4. 为注册表、资源路径安全、作用域包装、切换回滚和构建资源复制增加单测。
5. 运行 OsyC 单测、类型检查、Svelte 检查、生产构建和 iOS 15 兼容性检查；真实桌面/iOS 验收后再扩展其余主题。

## 约束

- 仅纳入许可证允许再分发的主题，并在插件包中保留许可证与来源信息。
- 不纳入 GPL-3.0 的 AnuPpuccin，除非 OsyC 另行确定 GPL 分发边界。
- 不在运行时从 GitHub 或其它远程地址拉取主题。
- 不修改已发布的 `1.0.75`，试点不预留或发布版本。
